# Project Hecate

**Status:** Reusable technology project\
**Type:** Preview Array transformation-system integration

## Purpose

Project Hecate integrates Aura-Matrix Preview Array rendering technology with supported configuration choices from the NAS Integration Suite and OAM Aura-Matrix V-10.

The project begins with a simple question from the MC: if these systems can offer extensive bodily and presentation choices, why shouldn't the user be able to see those choices before deciding whether to execute them?

Hecate allows supported NAS and OAM configuration choices to be rendered through Preview Array technology before execution.

**Hecate shows the paths. She does not choose one.**

A preview does not authorize, schedule, initiate, or execute a transformation or treatment.

## Story-State Boundary

Project Hecate is a reusable project rather than an inherent capability of NAS, OAM, the Preview Array, or Lesbos Estate.

In a story using the participating technologies, the MC may propose the project and it may subsequently be developed and deployed.

The existence of NAS, OAM, the Preview Array, or Lesbos Estate does not by itself establish that Project Hecate has been proposed, completed, or installed in that story.

The reusable Lesbos Estate baseline does not include completed Hecate integration. Any completed installation belongs to the continuity of the story that establishes it.
