# St. Claire — Recovered Organizations

Status: OPERATIONAL STRUCTURED DATA — RECOVERED FROM ESTABLISHED ST. CLAIRE SOURCE

This file supplements `St Claire 05 Organizations.md`. It restores organizations and civic functions that survived in established St. Claire source/current concept but were dropped from the maintained Organizations dataset during consolidation. Recovery preserves established function and named personnel where source supports them; missing template fields remain unresolved rather than being invented.

The closed-structure rule matters here: distinct community-sharing, commercial, civic, and infrastructure functions may coexist. A mutual-aid exchange does not replace a tool library; a tool library does not replace a hardware store; community infrastructure does not erase ordinary commerce.

## Explicit Non-Recoveries / Successions

These source names are not restored as additional organizations because their distinct function is already represented in current structured data:

- `Hearth & Hammer (Tool Library & Workshop)` → current `St. Claire Tool Library` owns the tool-library/workshop function.
- `St. Claire Hardware & Home Goods` → current `Fenwick Hardware` owns the ordinary for-profit hardware-store function.

This is functional succession, not a claim that community sharing replaces commerce.
