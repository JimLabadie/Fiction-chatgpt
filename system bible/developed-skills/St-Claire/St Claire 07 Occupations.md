# St. Claire — Occupation Lookup List

A flat list of generic, reusable job types, organized under the same categories as the Master Category List in St_Claire_00B_Rules_and_Mechanics.md. This list holds only occupations that generalize across many organizations (e.g. "electrician") — it does not hold organization-specific titles (e.g. "President, Llama Riders Club of St. Claire"), which live in that organization's own record in St_Claire_05_Organizations.md instead.

Built retroactively from what's actually in use across St_Claire_03_Population.md (170 people). Going forward, new Character entries should reference an entry here rather than inventing free-text occupations, and new occupations get added here as they're actually needed.
