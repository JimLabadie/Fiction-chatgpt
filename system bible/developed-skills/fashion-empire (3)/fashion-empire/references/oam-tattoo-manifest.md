# OAM Tattoo Module — Technical Manifest

*Part of the Aura-Matrix V-10's Multi-Needle Micro-Pigmentation Array. Selection happens via consultation before execution — see the Consultation & Selection Process note in `presentation-technology.md`.*

## Style Categories

| Style | Description |
|---|---|
| Fine-line | Delicate single-needle linework, minimal shading |
| Micro tattoo | Fine-line, under 1 inch, extremely detailed at small scale |
| Blackwork | Solid black fill, bold graphic linework |
| American traditional | Bold outlines, limited saturated color palette |
| Neo-traditional | Traditional base with expanded color depth and detail |
| Watercolor | Soft blended color, no hard outlines |
| Realism/portraiture | Photorealistic rendering, black & grey or full color |
| Geometric/dotwork | Pattern-based, sacred geometry, stippling |
| Illustrative | Linework plus shading, storybook/etching style |
| Floral/botanical | Detailed plant and flower motifs |
| Script/lettering | Calligraphy, block, or custom font text |
| Celestial | Stars, moons, constellations, astronomical motifs (fine-line or illustrative) |
| Custom gradient | Multi-color blended fields — includes pride-flag gradients as one option among others |
| Single-line/minimalist | Continuous unbroken line, no lift |

## Placement Zones
Wrist, inner forearm, outer forearm, upper arm, shoulder, upper back, lower back, full back, ribs, chest, collarbone, hip, thigh, ankle, behind the ear, nape of neck, spine, finger.

## Size Options

| Size | Range |
|---|---|
| Micro | Under 1 inch |
| Small | 1–3 inches |
| Medium | 3–6 inches |
| Large | 6–12 inches |
| Statement/full piece | 12+ inches, sleeve, or back piece |

## Color Options
Black & grey, full color, single accent color, custom gradient (including pride-flag and other multi-tone blends).
