# Mandatory Source-Grounded Drafting

Status: GOVERNING WORKFLOW RULE

Before producing story prose, first retrieve and apply `00-module-router.md`. Use its trigger scan to identify the complete set of reusable System Bible modules materially implicated by the scene. Then retrieve the current authoritative story artifacts and every module matched by the router. Do not draft from summaries, memory, prior conversational context, or an ad hoc source list when authoritative repository material is available.

The router step is mandatory because source discovery is part of source grounding. A receipt showing only the sources the writer happened to remember is insufficient. Multiple modules may trigger from the same scene; check all router entries rather than stopping after the first plausible match.

Identify and apply relevant concrete source details. Retrieval is not sufficient by itself: when a source contains established geography, locations, institutions, culture, relationship rules, character facts, terminology, physical details, or other scene-relevant specificity, use that material where naturally relevant rather than silently substituting generic equivalents.

If a matched source creates a meaningful conflict, unresolved prerequisite, or boundary question, report it before silently drafting around it. If required sources cannot be retrieved, report that and do not silently substitute generic material.

After drafting, audit the prose against the same retrieved router-selected sources for contradiction, omission of established specificity, voice continuity, continuity with accepted story, and accidental invention.

## Drafting receipt

Whenever a chapter or substantial story scene is delivered, provide a short source receipt outside the prose listing the router and authoritative files/modules actually retrieved for that draft. This receipt is evidence of retrieval, not proof by itself that the sources were applied correctly.

Example:

`Sources loaded: 00-module-router; character-bible; voice-and-style; current-story-state; previous approved chapter; 07-st-claire; 06-sapphic-culture; 03-relationships-family-and-polycule`

## Scope

This is a reusable system-level drafting rule. It applies across stories that use the shared repository framework. Story-specific canon remains subordinate to the project's established authority hierarchy; this rule governs the process used to discover, retrieve, and apply that canon, not the substantive story facts themselves.
