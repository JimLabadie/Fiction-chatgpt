# Lesbos Inherited Shell and Unit Ledger

Status: CONTROLLING INHERITED STRUCTURE WITH RECORDED ADAPTATIONS
Authority: CONTROLLING SPACE PROVENANCE AND ALLOCATION LEDGER

## Purpose

The Estate remains physically accountable to the mall it converted. This ledger prevents new rooms from appearing without space, protects useful inherited infrastructure, and identifies which assignments are permanent, provisional, or reserve.

## Status rule

An adaptation described as reserve remains physically available but not necessarily activated. Permanent program changes must update both this ledger and the main space ledger so the same inherited unit cannot be assigned twice.
