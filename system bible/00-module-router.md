# Mandatory System Module Router

Status: GOVERNING WORKFLOW
Scope: ALL STORY DEVELOPMENT, CONTINUITY, REVISION, AND DRAFTING

## Purpose

The System Bible contains reusable modules that function like skills. They are not useful if a writer must remember from prior conversation which module exists. This router is the mandatory discovery layer.

Before substantive story work, retrieve this router first. Match the requested task, planned scene, characters, setting, relationships, objects, technologies, and continuity questions against the triggers below. Retrieve every matched controlling System Bible module before analysis or prose. When a matched parent module points to a detailed reference that is relevant to the task, retrieve that detail too.

Do not rely on memory, story summaries, or a previously loaded subset to decide that an omitted module is irrelevant. Multiple modules may trigger from one scene. Err toward loading an overlapping module when its trigger is plausibly implicated; source conflicts are cheaper than invisible omissions.

The archived `developed-skills/**/SKILL.md` files are recovery evidence for routing intent. Operating canon remains the harmonized System Bible parent/detail records. A developed skill may help identify that a module should load, but it does not override the controlling System Bible.

## Mandatory routing sequence

1. Retrieve this router.
2. Describe the task/scene internally in concrete nouns and actions: who is present, where, what relationships are active, what identities/presentations matter, what technology/institutions/property/money are involved, and whether any transformation or age/life-stage issue is active.
3. Match that description against ALL module triggers below, not merely the most obvious one.
4. Retrieve every matched parent module and relevant linked detail.
5. Retrieve story-local authority: Master/Series Bible, Character Bible, Timeline/Continuity, Current Story State, Voice/Style, and the immediately relevant accepted prose as required by the task.
6. If a matched module creates a conflict or unresolved prerequisite, stop and report it before silently drafting around it.
7. Draft/analyze only after routing is complete.
8. Audit the result against the same loaded modules.
9. For prose, provide the source receipt required by `00-mandatory-source-grounded-drafting.md`, including this router and all matched modules actually retrieved.

## Reusable module triggers

### 01 — System and Canon Framework
Path: `system bible/01-system-and-canon-framework.md`

LOAD WHEN:
- determining canon authority, story-vs-shared-world ownership, MC/persona binding, consent/agency, identity interpretation, intimacy boundaries, recovery evidence, or conflict resolution;
- a task may alter reusable canon or needs a ruling about what source controls;
- material power intersects with romance, employment, housing, healthcare, wealth, property, or institutional belonging;
- uncertain which record is allowed to establish a fact.

This is also the fallback governance module when routing itself is ambiguous.

### Gender Presentation Culture routing supplement
LOAD WHEN transgender, nonbinary, or gender-nonconforming presentation/transition/community culture; passing/being-read-as; presentation methods; learned presentation competency; or gendered interpretation of appearance materially matters. Pair with Sapphic Culture when a trans sapphic character or sapphic presentation context is involved.

### Wealth Management routing supplement
Recovered skill routing intent: load when an ultra-wealthy anchor character's actual financial/legal structure matters: trusts, holding companies, family office, partner-protection structures, or corporate-empire scaffolding. This concerns how money/property/control is legally organized, not merely how much exists or what is purchased. Keep it distinct from Estate architecture and Fashion Empire business operations.

## Cross-trigger examples

These examples are routing examples, not story canon.

- A trans woman enters a lesbian bar in St. Claire and meets a closed polycule: load 06 Sapphic Culture + gender-presentation detail + 07 St. Claire + 03 Relationships/Family/Polycule, plus story-local character/continuity/voice records.
- A member of a closed polycule begins flirting with or dating someone outside it: load 03 before deciding whether the action is allowed, a violation, or requires prior discussion.
- A sapphic character wears a violet pendant: load 06 for cultural meaning and 10 for physical item specification if the item itself must be designed/described.
- Characters move into the Estate after becoming extremely wealthy through the Fashion Empire: load 08 Estate + Wealth Management + 12 Fashion Empire, plus 01/Hestia if relationship/property power is implicated.
- A transformed adult reclaims an age-associated experience: load 04 Transformation + age-culture/life-stage material + 01 identity/agency governance, plus any setting/culture module implicated by the experience.

## Router maintenance rule

Whenever a reusable System Bible parent module or developed skill family is added, renamed, consolidated, or materially changes scope, update this router in the same work session. A module that exists but cannot be discovered is operationally broken.
