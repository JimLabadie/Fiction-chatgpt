# Halloway Park

Status: MAINTAINED SHARED-WORLD CANON
Authority: SYSTEM BIBLE — ST. CLAIRE
Scope: REUSABLE ST. CLAIRE SETTING

## Established setting facts

**Halloway Park** is an established reusable location in St. Claire.

**The Hollow** is an established area within Halloway Park. It has **wooded ravine terrain** and **true forest cover**, giving it a genuinely secluded, separated-from-the-world quality suitable for quiet walks and private conversation.

## Reuse rule

Halloway Park and The Hollow belong to the reusable St. Claire world. Stories set in or using St. Claire may use these maintained setting facts without creating a separate story-local version of the park.

Story-specific events, memories, relationships, and character associations that occur there remain story-local unless separately established as shared-world canon.
