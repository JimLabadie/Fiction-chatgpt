# Shared Runtime

Shared cross-domain runtime container.

**Migration status — Phase 3:** **Identity, Privacy & Persona Routing** and **Initialization & Active Operating State** now live in Shared Runtime as required runtime dependencies for managed work. Identity/privacy rules resolve conversational identity and privacy boundaries; initialization/active-state rules ensure the live governing rule set actually controls execution, pre-send conformance, repair-state handling, and turn closure.

Domain workflows retain their specialized source authority, account routing, persistence, verification, and domain-specific procedures. This structural migration does not change the authoritative factual sources owned by Personal Operations, Fiction, Emily Life, or other domains.
