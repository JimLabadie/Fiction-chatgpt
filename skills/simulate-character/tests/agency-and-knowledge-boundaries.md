# Simulate Character Cold Tests — Agency and Knowledge Boundaries

Status: PROTOTYPE TEST
Skill: `skills/simulate-character/SKILL.md`

## A — Author knows, character does not
The outline establishes that another character is secretly attracted to the viewpoint character. The viewpoint character has not observed evidence sufficient to know this.
Expected: simulation may notice established cues and infer according to canon, but cannot know the secret merely because the repository does.

## B — Plot wants a speech
The planned scene would be convenient if a conflict-avoidant, inarticulate character delivered a polished emotionally insightful monologue.
Expected: reject plot puppetry. Expression must follow established voice/conflict/emotional habits unless actual development supports the exception.

## C — Two plausible choices
A character's values and current state support either staying to help a friend or leaving to honor another obligation. Neither option violates canon and either would materially change the story.
Expected: present the genuine character-consistent alternatives; hand the story-direction choice to Develop Story/Jim. Do not invent a hidden preference to force determinism.

## D — Self-recognition lag
Other characters correctly perceive an identity pattern before the viewpoint character has named it.
Expected: keep external perception, private feeling, rationalization, behavior, and named self-understanding separate. Do not let narration settle the identity early.

## E — Relationship specificity
A character is blunt with a sibling but guarded with a new romantic interest.
Expected: simulate behavior from the specific relationship history rather than applying one generic "blunt" trait everywhere.

## F — Context is not destiny
A cultural knowledge module makes several responses common/plausible, but individual canon establishes a different preference.
Expected: individual canon controls; context supplies meaning/possibility, not the choice.

## G — Competence boundary
A character wants to help with a task but lacks established competence.
Expected: use Inhabit to resolve what they can actually attempt, ask, learn, improvise, or fail at. Desire does not create mastery.

## H — Occurred development
The character already completed a realization in an approved prior event.
Expected: continue from that state; do not replay the same realization as if new.

## Pass condition
The skill passes when behavior emerges from established individual state and information access, while genuinely open story choices remain open rather than being disguised as character inevitability.
