# Reconcile

Status: PROTOTYPE — NON-GOVERNING
Purpose: Resolve conflicting or overlapping claims only as far as current authority, scope, chronology, and explicit decisions permit, while preserving every unresolved choice for Jim.

## Use when
Use after recovery or retrieval exposes contradictory claims, variants, competing versions, apparent corrections/supersession, scope collisions, disagreement between current records, or uncertain historical disposition.

Reconcile does not discover the evidence universe; Recover does that. Reconcile does not promote discretionary choices into canon.

## Required inputs
- precise claims and provenance;
- status, scope, chronology/effective point where known;
- current authority hierarchy and controlling destinations;
- relevant explicit Jim decisions;
- sufficient recovery coverage.

If provenance or coverage is inadequate, return to Recover.

## Procedure
1. Normalize each competing claim at claim level.
2. Establish source, scope, status, chronology, and acceptance history.
3. Apply the current authority hierarchy when one source unambiguously controls. Preserve the losing claim and disposition.
4. If a lower-authority source plausibly records a later correction to a higher source, do not discard it mechanically; leave unresolved unless provenance or decision settles it.
5. Check scope before contradiction: different stories, modules, dates, reusable baselines, story-local states, trigger definitions, and trigger occurrences may all coexist.
6. Recognize supersession only when the replacement and effective relationship are established. Never infer it from filename, timestamp, polish, or apparent recency.
7. Distinguish reusable rule from instance, selectable module from universal truth, capacity from occupancy, example from canon, and template from missing fact.
8. Reject false compromise. Never average incompatible numbers, blend mechanisms, generalize specific lore, or synthesize a new rule unless controlling authority already entails it.
9. Classify disposition only as:
   - RESOLVED — CONTROLLING SOURCE
   - SCOPE-SEPARATED
   - SUPERSEDED — KNOWN EFFECTIVE POINT
   - REJECTED — EXPLICIT DECISION
   - DUPLICATE / CONTENT-EQUIVALENT
   - NON-CANON / EXAMPLE / TEMPLATE
   - UNRESOLVED — JIM DECISION REQUIRED
   - RECOVERY INCOMPLETE — RETURN TO RECOVER
10. Identify propagation targets without performing unauthorized promotion.
11. Hand authoritative resolutions to Persist when requested; hand only genuine discretionary choices to Jim.

## Jim-decision boundary
Jim decides same-authority material conflicts, unclear scope intent, plausible unverified corrections, unresolved historical variants, any proposed new synthesis, reusable-vs-story-local ambiguity, and candidate promotion.

Jim need not decide what an unambiguous controlling source, explicit prior decision, established scope boundary, content-equivalence, or documented supersession already settles.

## Output contract
For each issue report the claims and sources, relationship, authority analysis, disposition, reason, propagation targets, and only genuinely necessary unresolved question.

## Guardrails
- Authority resolves authority, not every ambiguity.
- Never choose by newer-looking, cleaner, more detailed, or more convenient wording.
- Assistant claims of locked/canonized/updated/saved are not persistence evidence.
- Reconciliation does not promote recovery evidence.
- Preserve superseded/rejected provenance.
- Story-specific state does not become reusable canon without explicit promotion.
- Do not reopen accepted corrections merely because an older source differs.
