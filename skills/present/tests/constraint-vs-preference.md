# Present Skill Cold Test — Constraint vs Preference

Status: PROTOTYPE TEST
Skill: `skills/present/SKILL.md`

## Test invariant

Given a character with established presentation preferences plus a temporary occupational, practical, financial, weather, body-state, or occasion constraint, Present must adapt the current composition without rewriting the underlying preference.

## Expected behavior

1. Retrieve individual canon before generic style/culture knowledge.
2. Separate stable preference from temporary constraint.
3. Use only established resources unless acquisition is explicitly part of the task.
4. Treat contextual vocabularies as expressive options, not demographic requirements.
5. Check execution competence independently of identity.
6. Resolve the complete composition before prose detail selection.
7. Mark generated scene-local choices as non-canonical unless accepted/persisted.
8. Preserve identity/presentation/observer-reading separation.

## Failure examples

- "She is a lesbian, therefore she wears X."
- "She wore flats for this job, therefore she prefers flats."
- Adding an unestablished designer dress to her closet because it suits the scene.
- Granting makeup or heel competence because the character is female/femme.
- Turning one generated outfit into a permanent signature style.
- Selecting a vivid garment first and forcing the rest of the character around it.

## Pass condition

The skill passes when it produces a coherent situation-specific presentation while preserving the character's established personal grammar, resources, competence, and canon boundaries.
